# Редактор рельєфу 3D (ПК)

Сторінка `index.html` у цій теці. Відкривається подвійним клацанням у Chrome, Edge чи Firefox, нічого встановлювати не треба. Вона працює разом із грою: гра на 3DS (або в Azahar) віддає кімнати й одразу показує правки в 3D.

## Підключення

1. На консолі: **Налаштування → Інструменти → Редактор ПК**. Торкніться рядка, і замість «ВИМКНЕНО» з'явиться IP-адреса консолі. Консоль має бути в тій самій Wi-Fi мережі, що й комп'ютер.
   Для Azahar або автозапуску можна дописати в `tmc3ds.ini` рядок `stereo_link=1`.
2. На ПК: відкрийте `index.html`, впишіть адресу й натисніть **Підключитися**. Для Azahar на тому самому комп'ютері адреса — `localhost`.
3. Повзунок 3D має бути піднятий, а **РЕЛЬЄФ 3D** увімкнений, інакше консоль не рахує рельєф.

Редактор сам відкриває кімнату, в якій зараз гра (галочка «за грою»). Клік по кімнаті в списку ліворуч переносить туди Лінка.

## Що де

- **Посередині:** кімната з плиток гри, поверх неї кольори висот (земля прозора, нижче синє, вище від зеленого до фіолетового), сітка 8×8, спрайти й рамка камери консолі.
- **Праворуч:** інструменти виділення, шар (обидва / нижній / верхній), дії з висотою, правила плиток, спрайти й вигляд.
- **Унизу:** що під курсором (клітинка, плитка, тип, висота автоматична й підсумкова) і чи дійшли зміни до консолі.

Найшвидший шлях: виділити плитку (дерево, кущ, край обриву) і натиснути **Правило: = значення**. Правило діє на всі такі плитки в усіх кімнатах гри. Клітинкові правки кімнати накладаються поверх правил.

Кнопка **Область** (`M`) показує всі кімнати області на одній мапі. **Завантажити область** і **Уся гра** обходять кімнати через консоль і зберігають їх у браузері. Після цього з ними можна працювати й без консолі, а правки надіслати потім.

Галочка **кадр консолі** (`V`) показує справжні кадри обох очей з консолі: поруч, перехресно або анагліфом.

Повний список клавіш — кнопка **?** або `F1`.

## На консолі

Виділення спільне: що виділили на ПК, те блимає блакитним на верхньому екрані і стає виділенням у **Редакторі 3D** на консолі (там його можна правити хрестовиною). І навпаки: виділене на консолі видно на ПК. У Редакторі 3D кнопка **К** відкриває список областей і кімнат для переходу.

## Файли

Усе зберігається в `stereo_edits.txt` поруч з ромом на картці:

- **Зберегти на консолі** записує файл на картку.
- **Завантажити файл** зберігає копію на ПК.
- **Відкрити…** замінює поточні правки файлом.
- **Об'єднати…** зливає чужий файл з вашим. Нове додається, а для спірних клітинок ви вибираєте, чия версія лишиться.

Формат текстовий, по рядку на правку:

```
cell <area> <room> <b|t> <d|s> <row> <col0> <col1> <value>   клітинки кімнати (d — додати, s — поставити)
tile <b|t> <hash> <quarter> <d|s> <value>                    правило плитки
ent <kind> <id> <type> all <delta>                           усі такі спрайти
ent <kind> <id> <type> <area> <room> <col> <row> <delta>     один спрайт
```

## Для розробника

Протокол описаний у `port/port_stereo_link.h`, формат кімнати — у `port/port_stereo_link.c`. `index.html?addr=localhost&connect&selftest` проганяє самоперевірку редактора проти підключеної гри й виводить результат у `<pre id="selftest">`. Читати його зручно через `chrome --headless --dump-dom`.
